September

A dozen agents and a harness

Fermat's Last Theorem stood unproven for about 350 years; Andrew Wiles's proof took him seven years, and formalizing it, checking every step by computer in Lean, has been a major effort since. In September, Anthropic published that Claude had done it.

“We started with a team of about a dozen agents.”00:00:13

Early on the team didn't work well, so they gave it a proof-orchestration platform that managed the project's state as a graph the agents could query.

“Think about it as like a very domain-specific harness.”00:00:13

That result also leaned on extensive analysis and support from researchers.

Fable 5.2

A thousand agents, git and a database

“So going from a dozen to a thousand.”00:02:06

No domain knowledge, no proof platform, and:

“And with no human steering, with respect to the solution.”00:02:06

The setup is mostly about safety: each agent runs in its own sandbox with restricted network access, with real-time monitoring and an offline review of runs every ten minutes. What the agents get to work with is short:

“Two different things: Git and a SQL database.”00:02:06
“It establishes one lead agent, 999 helper agents.”00:02:06

The prompt tells them about git, the database and the problem statement, and that's all.

From the notes: “Fable 5.2 is doing massive multi-agent work with no human steering” and “they give the primitive git and a SQL database”. The reading: the structure Anthropic built is all safety (sandboxes, monitoring), and none of it is domain help. That's the “Less harness, more model” theme from Philipp Schmid, pushed to a thousand agents: give them a computer and a shared store, not a toolbox.

The spine

The lead built the tables in five minutes

“Five minutes in the run, basically created these database tables.”00:03:46
“We didn't tell them to.”00:03:46

The lead created a table to announce things, one to assign workers, an open board for notes, a shared to-do list of subtasks, and a log of finished work his slide calls Landed. A chart of the run shows the lead posting to the announce table now and then, assigning helpers to statements in the theorem, and the helpers reading and writing as they go.

“So agents now are sufficiently advanced that they can actually build primitives if they need to solve hard problems.”00:03:46
“This ran for around 30 hours.”00:03:46

For one of the hardest parts of the proof, the team built its own task tree of dependencies.

“They actually developed their own abstraction.”00:03:46
From the notes: “the agent created the database tables within 5 minutes, coming up with the coordination”, and “follow up on giving the agent a database to store stuff”. The reading: the database became the team's shared work surface: a message board, a job queue and a log the agents designed for themselves. It's the shape of Lovable's inbox per agent and Yegge's beads, except nobody built it in advance. For the follow-up: what's the minimum shared store, and what should the agent be left to design on top?

The result

Thirty hours, no harness

Over the run the lead and the helpers reallocated themselves across the sixty statements in the proof as each was solved.

“So the point of all this is really just to kind of highlight: agents can solve very long horizon problems without much.”00:05:27

One note an agent left near the end, as the work was frozen:

“Magnificent work all night.”00:05:27
“And agents are getting increasingly good at orchestrating themselves.”00:05:27
From the notes: “Magnificent work, all 999 of you.” The recording has “Magnificent work all night”; his post on the run, on the links page, confirms the one lead and 999 helpers. The reading: this sits against Steve Yegge's lesson that the more agents he runs, the more people he needs. Here a thousand agents ran thirty hours with no human steering the solution, though with people watching for safety every ten minutes. The difference is the task: a formal proof checks itself in Lean, so the team always knows whether it's right. For a client: does their task have that kind of check?
