# Notes

What the microphones and the camera miss: the observation, the question you
asked, the link someone mentioned, the thing to look up later.

```
notes/
  inbox/        one file per capture
  research/     an /talk-ask or /conference-themes answer kept on purpose
```

Capture with `/conference-capture`; it timestamps in the event timezone and links the
session when it can. A note is evidence, not a summary: write what was said or
seen, not what you concluded a week later.

A `kind: todo` note also lands in [`../editorial/backlog.md`](../editorial/backlog.md).
