01 · The demo

An agent added an email to a waitlist. The UI said success. The room reloaded, and the list was empty. The agent had checked the half it could see.

That is the normal shape of the failure: not a crash, but a green check on the wrong thing.

02 · The check

A prompt is a request. A run is a check.

A paragraph that says “verify the work” can be forgotten, skipped, or interpreted. A script that exercises the app returns the same observation every time and gives the agent a failure it can repair.

The point is not to over-prescribe the path. The point is to give the agent a way to see the result.
