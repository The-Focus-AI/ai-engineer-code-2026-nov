# Custom skills

The 12 skills below are part of this repo, not the installed pstack/mattpocock
set. They use two families: **`conference-*`** for build-wide operations and
**`talk-*`** for one talk at a time.

| Old call | New call | Object |
| --- | --- | --- |
| `/new-conference` | `/conference-init` | build |
| `/next` | `/conference-next` | build |
| `/capture` | `/conference-capture` | build |
| `/backlog` | `/conference-backlog` | build |
| `/hooks` | `/conference-hooks` | build |
| `/magazine` | `/conference-magazine` | build |
| `/explainer` | `/conference-explainer` | build |
| `/atlas` | `/conference-atlas` | build |
| `/talk-themes` | `/conference-themes` | corpus |
| `/ask-talks` | `/talk-ask` | talk |
| `/polish-talk` | `/talk-polish` | talk |
| `/talk` | `/talk-page` | talk |

The old names are retired. The 61 upstream skills keep their names.
