Own the verification loop

Trust in agent-generated systems comes from owning the verification loop—deterministic rules, stakes-scaled credentials, replayable execution traces, hardened sandboxes, and continuous failure diagnosis—rather than line-by-line diff review.

As generation drops to minutes, human diff review becomes the bottleneck and fails silently against compounding slop or benchmark gaming. Teams maintain quality at scale by converting corrections into code-enforced lint rules and invariants, gating tools by risk via Token Vault scopes and CIBA approvals, running agents in isolated VMs with video/trace artifacts, and closing an immune-system production loop that catches, diagnoses, remembers, and regression-tests failures—including cross-checking uncalibrated LLM judges in shadow mode.

Brownfield & demand factories

Because coding tokens make small teams look huge on existing products with live runtime feedback, agentic software factories thrive on brownfield maintenance—bounded by real token/fuel economics and durable multi-hour execution.

When code generation is cheap, tiny pods (20–30 people, single high-equity units) ship and operate enterprise-scale products without traditional SaaS bloat or Jira ceremonies. However, greenfield 'open-ended discovery' factories amplify noise; factories excel on brownfield systems where customer telemetry and production SLAs define crisp promises to keep. Running long-horizon autonomous factories (and Demand Factories that extend the product envelope) is bounded less by code syntax than by compute fuel costs, sub-day sandbox durability across deploys, and steering multi-hour subagent loops.

Delete the harness

Stop over-engineering orchestration wrappers that models absorb every release; delete brittle scaffolding and invest in millisecond sandboxes, fast tool execution, semantic tool surfaces, and one shared organizational agent with public traces.

Prompt hacks, multi-step retrieval scaffolds, and tunnel-vision per-API wrappers degrade models and burn tokens as foundation models gain native bash/computer-use fluency. Teams achieve 3–4× speedups and fewer tokens by deleting 80–90% of harness glue each model generation while investing in durable infrastructure: instant-forking micro-VMs, edge low-latency runtimes where inference speed shifts bottlenecks to tool calls, and a single shared company agent whose public traces build institutional knowledge—though vertical domains still require workflow-specific harnesses encoded with expert taste.

System One decision models

Sub-second, reliably calibrated decision models turn AI from heavy conversational chatbots into a programmatic fourth logic gate—running inside DuckDB queries, UI keystrokes, and live web-grounded pipelines.

Large frontier models are too slow and RLHF-sycophantic to use as inline software branching logic, and ungrounded LLMs suffer fatal overconfidence. Dedicated 'System One' decision models (Clef, Jev, TypeSafe, Grounded Decision Models backed by live 100B-page search indexes) deliver calibrated typed booleans, rankings, and citations under 1 second at roughly $1 per 1,000 requests—replacing entire embedding/vector-DB stacks and turning natural-language judgment into an ordinary composable function across SQL rows, search UIs, and routing boundaries.

Modeled context over connectors

Wiring agents to dozens of live source connectors creates fragile chaos; reliable enterprise AI depends on unified permission-filtered indexes, warehouse data modeling, and actively pruned agent memory.

MCP solved plumbing, not answering: connecting an agent to live Slack, Jira, Drive, and operational databases leaves it guessing which source is canonical, violating ACLs, and drowning in contradictory context. High-leverage data and platform teams invest in the durable warehouse/semantic layer—building unified pre-computed search indexes with document-level ACL metadata attached at ingest—while curating agent memory through continuous scoring, consolidation ('dreaming'), and pruning so stale instructions do not poison future runs.

Judgment when code is free

Zero-cost implementation shifts engineering value away from typing syntax toward human judgment, taste, ambition, and deliberate attention budgets—protecting teams from high-speed burnout.

Instant generation reverses 30 years of workflow economics: reviewing a 1,000-line PR takes just as much human cognition even when generating it costs $0. Builders must triage effort by 'expected pain' (probability of change × cost of changing later)—locking irreversible database schemas and interfaces carefully while keeping UI specs loose and visual. At the same time, compulsive multi-agent tabs trigger acute decision fatigue unless organizations shift away from ticket queues toward shared intent layers, extensible platforms, and bold ambition.
